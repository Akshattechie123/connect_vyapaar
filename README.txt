Pages:  index.html  services.html  marketplace.html  pricing.html  about.html  contact.html  legal.html
Shared: style.css (design)   main.js (menu, tabs, forms, search, animations)
Images: logo.png  logo-mark.png  favicon.png

1. Phone: replace "+91 XXXXX XXXXX" in every .html file with your real number.
2. WhatsApp: open main.js and set  whatsapp: "919876543210"  (country code + number, digits only).
   Forms then open WhatsApp with the message ready, and a floating "Chat with us" button appears.
   While it is empty, forms show the request with "Email this request" and "Copy" buttons.
3. CIN / GSTIN: replace "to be added" in footer, about.html and legal.html.
4. legal.html is a draft: have a lawyer / CA review it.
5. Hosting: upload all files to your hosting root. For a real form backend (saved leads) ask your
   developer to connect the forms in main.js to your CRM or an API.
